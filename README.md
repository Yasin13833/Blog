# 🚀 Blog – Full-Stack Product Management Platform

A modern full-stack platform for showcasing and managing products, brands, and categories. Built with React, Node.js, Express, and MongoDB, featuring a multilingual public website and a dedicated admin dashboard.

---

## ✨ Features

- 🌍 Multilingual support (Persian, English, and Arabic)
- 📱 Fully responsive user interface
- 🛍️ Product catalog and detailed product pages
- 🗂️ Product categories and brand management
- 🔐 Secure authentication with JWT
- 👤 Role-based access control
- 🖼️ Image and media uploads
- 🔎 Product search and filtering
- 📄 Pagination and sorting
- ⚡ RESTful API architecture
- 📚 API documentation with Swagger
- 🛡️ Centralized error handling and request validation

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Yasin13833/Blog.git
cd Blog
```

### 2. Back-End

```bash
cd Back
npm install
npm run dev
```

### 3. Front-End

```bash
cd Front
npm install
npm run dev
```

### 4. Dashboard

```bash
cd Dashboard
npm install
npm run dev
```
